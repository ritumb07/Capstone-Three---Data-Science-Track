# 🏛️ Government Budget Intelligence & Forecasting System

**A Data Science Capstone Project** — Budget Analysis, Variance Detection, and Multi-Year Budget Projection

---

## 1. Business Problem

> *Based on historical budget execution, current-year spending patterns, planned requirements, and
> organizational/workload drivers, what will our future budget requirement look like — and where
> are we likely to have variances or funding risks?*

Government agencies (and any organization on an annual appropriations cycle) repeat this question
every budget season. This project builds an end-to-end, reproducible analytical pipeline that turns
historical financial data into:

1. A **defensible next-fiscal-year budget forecast**, by department and category
2. A **ranked list of funding-risk lines** (overrun risk, chronic underspend / lapse risk, unexplained rapid growth)
3. An **explainable model** budget analysts can actually justify to leadership and auditors
4. An **interactive dashboard** for self-service drill-down

This is designed as a **portfolio-grade capstone** demonstrating the full data science lifecycle:

```
Data Engineering → EDA → Feature Engineering → Statistical Analysis → Time Series →
Machine Learning → Forecasting → Model Evaluation → Explainability → Dashboard → Recommendations
```

## 3. The Dataset

**⚠️ This project ships with a SYNTHETIC dataset** (`src/generate_data.py`, seeded for
reproducibility) so it runs immediately with no access restrictions. It is deliberately modeled on
the structure of real public-sector financial systems — appropriation → allocation → obligation →
expenditure — across:

- **8 departments** (Public Safety, Health & Human Services, Transportation, Education,
  Administration & Finance, Environment, IT, Parks & Recreation)
- **5 spend categories** (Personnel, Operating, Capital Outlay, Grants, Contracted Services)
- **8 fiscal years** (FY2019–FY2026, with FY2026 as a partial current year — 8 months of actuals)
- Monthly-level obligation detail for seasonality analysis
- Department workload drivers (caseloads, service volumes, FTEs)
- Agency-wide macroeconomic indicators (inflation, COLA, unemployment, interest rates)
- 10 multi-year capital projects with realistic schedule/cost slippage

**To use real data:** replace the five CSVs in `data/raw/` with extracts from your GL/ERP/budget
system using the same column schema (documented in the data dictionary below), then re-run the
notebook from Section 2 onward. No other code changes should be required.

### Data Dictionary (key fields)

| Table | Key Columns |

| `budget_master.csv` | `fiscal_year, dept_id, dept_name, category_id, category_name, budget_allocated, actual_spend, variance_amount, variance_pct, is_partial_year` |

## 4. Methodology / What the Notebook Does

| # | Stage | Techniques Used |
|---|---|---|
| 1 | **Data Engineering** | Multi-source ingestion, referential/reconciliation validation, merge into master analytical table |
| 2 | **EDA** | Trend analysis, department/category composition, seasonality (year-end spending spike), correlation analysis |
| 3 | **Feature Engineering** | Lag features, rolling averages/volatility, execution-rate history, workload ratios, structural budget shares, capital pipeline exposure |
| 4 | **Statistical Analysis** | SPC/control-chart variance monitoring, z-score anomaly flags per budget line, one-way ANOVA across departments |
| 5 | **Time Series Forecasting** | Holt-Winters exponential smoothing (agency-wide and per-department baseline forecasts) |
| 6 | **Machine Learning** | Gradient Boosting Regression to predict next-FY spend from engineered features |
| 7 | **Model Evaluation** | **Walk-forward backtesting** (no look-ahead bias) across 3 historical years; MAE / RMSE / MAPE vs. a naive persistence baseline |
| 8 | **Explainability** | SHAP values — global feature importance and per-prediction attribution |
| 9 | **Risk & Anomaly Detection** | Isolation Forest (multivariate outliers) + transparent rule-based risk categories (overrun / lapse / rapid growth) |
| 10 | **Interactive Visualization** | Plotly sunburst, grouped bar forecast comparison, drill-down line charts |
| 11 | **Business Recommendations** | Executive summary translating model output into specific, actionable guidance |

### Why walk-forward validation matters
A random train/test split would leak future information into the training set (e.g., using FY2025
data to help predict FY2023). We instead train only on years *before* the test year at each step —
the same constraint a real budget analyst faces — which gives an honest estimate of how the model
would have performed in production.

## 5. How to Run

```bash
# 1. Set up environment
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 2. Generate the synthetic source data (or drop in your real extracts to data/raw/)
python src/generate_data.py

# 3. Run the full notebook (already pre-executed and included in this repo, but you can re-run it)
jupyter nbconvert --to notebook --execute --inplace notebooks/Capstone_Budget_Intelligence.ipynb

# 4. (Optional) Launch the interactive dashboard
cd dashboard
streamlit run app.py
```

The notebook writes intermediate tables to `data/processed/` and exports all static charts to
`reports/figures/` as it runs, so the dashboard and any downstream reporting can consume its output
directly.

## 6. Key Results (from the included run)

- **ML-forecasted next-FY agency-wide budget requirement**, with department-level breakdown and a
  Holt-Winters cross-check for governance purposes
- **Backtested MAPE around 7–8%** for the Gradient Boosting model vs. **~9–11%** for a naive
  year-over-year persistence baseline — consistently better across all backtested years
- **~10 budget lines flagged** for funding-risk review each cycle (overrun risk, chronic
  underspend/lapse risk, or unexplained rapid growth), representing several hundred million dollars
  of spend exposure in the sample data
- **Top forecast drivers (via SHAP):** prior-year actuals, 3-year rolling average spend, and
  historical execution rate — validating that disciplined trend + execution-rate analysis is the
  right lens for this forecasting problem
- A recurring **year-end "use-it-or-lose-it" spending spike** (~26% of annual obligations in the
  final fiscal quarter) that materially affects mid-year run-rate projections if not corrected for

See the notebook's final section (**Executive Summary & Business Recommendations**) for the full
write-up, including specific recommendations by department/category.

## 7. Extending This Project

- **Swap in real data** — the pipeline is schema-driven; point it at your agency's GL/ERP extracts
- **Add a supervised risk label** — once several budget cycles of "confirmed risk outcome" exist,
  replace the rule-based risk flags with a trained classifier
- **Automate drift monitoring** — track backtested MAPE each cycle; trigger retraining if it
  degrades beyond a threshold
- **Scenario/what-if analysis** — parameterize the macro assumptions (inflation, COLA) in the
  dashboard so budget officers can stress-test forecasts under different economic conditions
- **Multi-year (not just 1-year-ahead) forecasting** — extend the walk-forward framework to
  recursive multi-step forecasts for 3–5 year capital/strategic planning
